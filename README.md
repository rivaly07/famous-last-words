This program writes one UTF-8 epitaph line of at most 150 characters to `/output/entry.txt`: “Don't worry, I fixed the wiring myself. Watch this.”

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py && cat out/entry.txt
```
